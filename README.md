# 우리 집 냉장고, 모두 괜찮을까요?

냉장고 속 다진 소고기, 손질 멜론, 슬라이스 가공육의 보관 원리를 살펴보는 아시아경제 비주얼뉴스 시안입니다.

## GitHub Pages

저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`로 설정한 뒤 `main` 브랜치의 `/ (root)`를 선택하면 게시할 수 있습니다. `index.html`이 저장소 루트에 있습니다.
